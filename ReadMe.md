## Description

This tool aims to help Instagram users to track their data of following and followers.

Integrated with UI of Notion database views.

## Why Notion?

- ***Various Ready-made UI*** - It is quite easy to prototype with Notion database views, especially in need of data visualize functionaliy.
- ***Cloud Storage*** - An ultimate service must , from my perspective.
- ***Free and Well Known*** - 


And Notion has various limitation in the other hand, though. I have done my best to optimize the performance and simplfy the workflow, but it still lags and is complicated to a certain extent -- I may find 

## Features

- **Totally Free** - Work with only PC browser and a notion account.
- **Simple Workflow** - Take a snapshot of your account, and upload it to notion. (setup might be a little complicated though)
- **Privacy** - No authentication credentials, no account IDs or any of you and your friends' personal information will be cache in this tool, nor send to any third-party web server.
